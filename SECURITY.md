# Segurança e escopo público

Este repositório contém somente código de demonstração e registros sintéticos. Não adicione dados de pacientes, CPF, credenciais, dumps, tokens, arquivos `.env` ou documentos internos.

O pipeline não recebe uma base real; `pipeline/generate.py` cria sua própria entrada fictícia. A API é local, somente leitura, e não abre conexões com sistemas de saúde. A interface publicada no GitHub Pages usa um snapshot estático.

Se uma credencial for adicionada por engano, revogue-a ou troque-a imediatamente e trate o histórico Git antes de continuar a publicação.
